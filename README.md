# IRP 포트폴리오 대시보드 (개인용 · 암호화)

아버님 실제 보유종목·금액 데이터가 **AES-256-GCM으로 암호화되어** `index.html` 안에 그대로 담겨 있습니다.
비밀번호 없이는 파일 안의 데이터를 복호화할 방법이 전혀 없습니다(호스팅 업체·GitHub도 내용을 볼 수 없습니다).

- 암호화 방식: PBKDF2-HMAC-SHA256(310,000회) → AES-256-GCM
- 열람 비밀번호는 이 저장소 어디에도 없습니다. 만든 사람(관리자)에게 별도로 전달받으세요.
- 파일을 열면 비밀번호 입력창이 먼저 뜨고, 맞는 비밀번호를 넣어야 화면이 나타납니다.

## 이 사이트로 할 수 있는 것 / 없는 것

열람자는 모든 화면·표·차트를 볼 수 있고 정렬·검색·CSV 내려받기가 가능하지만, 매수·매도·배당 추가나
종목 수정 같은 편집은 할 수 없습니다(실수로 데이터가 바뀌는 것을 막기 위한 잠금이며 보안 장치는 아닙니다).

## 실시간 시세가 안 보인다면

이 사이트는 정적 파일이라 그 자체로는 실시간 주가를 가져올 수 없습니다. 별도로 배포한 시세 백엔드
(Vercel) 주소를 화면 우측 상단 **설정 → 시세 프록시 주소**에 한 번 입력해야 합니다. 백엔드 배포 방법은
`DEPLOY_GUIDE.md`를 참고하세요.

## 데이터 갱신 방법

원본 관리자 파일에서 데이터를 수정한 뒤 "암호화 공유 파일 만들기"를 다시 실행하면 새 `index.html`이
생성됩니다. 그 파일로 이 저장소의 `index.html`을 교체하고 다시 커밋·푸시하면 같은 주소에 최신 데이터가
반영됩니다. 비밀번호는 매번 새로 생성되므로, 열람자에게 새 비밀번호도 함께 전달하세요.

## 주의

이 파일에는 자산 금액이 (암호화된 형태로) 그대로 담겨 있습니다. 비밀번호는 신뢰할 수 있는 방법
(직접 전달, 문자메시지 등)으로만 전달하시고, 이 저장소의 커밋 메시지나 이슈 등 공개된 곳에는 절대
남기지 마세요.
